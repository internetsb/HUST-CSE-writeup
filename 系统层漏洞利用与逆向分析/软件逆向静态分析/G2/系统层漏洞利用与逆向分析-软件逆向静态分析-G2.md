发现`RC4`加密算法的特征，接下来只要根据`key`算出密钥流，由异或运算的可逆性，就可以解密加密的密文，得到flag。

## 代码

```python
# KSA 初始化S盒
def InitSbox(k):
    # 初始化S盒 存初始值0-255
    S = list(range(256))
    T = [] # 用于轮转存放key
    for i in range(256):
        T.append(k[i % len(k)])  # 存放轮转的256位key
    j = 0
    for i in range(256):
        j = (j + S[i] + T[i]) % 256
        # 通过交换，打乱S盒
        S[i], S[j] = S[j], S[i]
    return S

# PRGA生成密钥流
def encrypt_or_decrypt(m, k):
    c = ""
    i = j = 0
    # 调用已经初始化的S盒
    S = InitSbox(k)
    for x in range(len(m)):
        i = (i + 1) % 256
        j = (j + S[i]) % 256
        S[i], S[j] = S[j], S[i]  # 交换 打乱S盒
        t = (S[i] + S[j]) % 256
        # 将生成的密钥流key逐一与明文进行异或，格式化成16进制字符串
        c += '%02x' % (m[x] ^ S[t])
    return c
```
