`sub_14000149C`函数，地址`0x14000149C`，该函数根据输入的字节`b`，将`b`的高4位作为索引从`addr`中取出`result`高4位，将`b`的低4位作为索引从`addr`中取出`result`低4位，最后返回`result`

```c
__int64 __fastcall sub_14000149C(__int64 addr, unsigned __int8 b)
{
  __int64 result; // rax

  result = 16 * (unsigned int)*(unsigned __int8 *)(addr + (b >> 4));
  LOBYTE(result) = *(_BYTE *)(addr + (b & 0xF)) | (16 * *(_BYTE *)(addr + (b >> 4)));
  return result;
}
```
